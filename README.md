## ✨ Key Features

- **📱 Fully Responsive Design:** Seamless layout scaling across desktop, tablet, and mobile devices using Bootstrap grid and custom CSS media queries.
- **🍔 Collapsible Navigation Bar:** Sleek hamburger navigation menu with smooth dropdown toggle on mobile viewports.
- **🎨 Custom Styled Menu Sections:** Distinct styled containers featuring delicious categories (**Chicken**, **Beef**, and **Sushi**).
- **⚡ Clean & Lightweight:** Built using semantic HTML5 and clean CSS without heavy third-party bundle overhead.

## 🛠️ Getting Started

Follow these steps to run the project locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/patel1234-bit/coursera-test.git
```

### 2. Navigate to the project directory
```bash
cd coursera-test
```

### 3. Open in your browser
- Simply double-click `index.html` to open it in any modern browser, or
- Run using the **VS Code Live Server** extension for live reloading during edits.
